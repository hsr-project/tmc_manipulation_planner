これは何？
=============================

ロボットモデルを与えてプランナを使って，計画問題を解くライブラリ．
CBiRRT2を実装したものである．

Task Space Region
============================

本プランナで重要になる概念．詳細は参考文献[1]に詳しい．
Task Space Region(以下TSR)は，座標系に対する拘束空間を定義するものである．
TSRは，以下の要素から成り立つ．

1. 基準座標系からTSRまでの位置姿勢．(origin\_to\_tsr) T^0_w
2. TSRからエンドエフェクタまでの位置姿勢．(tsr\_to\_end) T^w_e
3. 境界を表現する(6x2)の行列．(min\_bounds, max\_bounds) B
4. 基準フレームから位置姿勢のサンプリング．T^0_s

TSRは基準座標から3.の行列で表現される超直方体の内部からなるSE(3)群である．
TSRを使って以下の演算が可能である．

1. 領域までの距離を出すこと
2. 領域からサンプリングすること
3. この領域に最も近い位置姿勢を出すこと


これらを利用することで逆運動学とRRTを融合させた運動計画が可能となる．

CBiRRT2
============================

BiRRTの機能拡張版．以下の点での機能拡張がなされている．

1. TSRを用いた拘束の追加
2. TSRを用いた，初期値，終端値のサンプリングによる動的追加
3. 関節角での複数初期値，終端値対応

である．オリジナルのCBiRRT2[1]でしめされている，TSRChainについては
外部リンク構造対応のIKが必要になるためと，必要性が薄いことから，
未実装となっている．

動作としては構造体CBiRRTRequestで

* 利用する関節名
* 初期全関節角
* 初期姿勢の集合
* 終端姿勢の集合
* 初期姿勢をサンプリングするTSRの集合
* 終端姿勢をサンプリングするTSRの集合
* 初期姿勢をTSRでサンプリングする際にIKの対象にならない関節の指令値　
例：　手先を操作する際の首とか，指．利用する関節角名には入っている必要がある．
* 終端姿勢のTSRでサンプリングの際にIKの対象にならない関節の指令値 同上
* 拘束となるTSR(ベクトルになっているが第１要素のみ有効)
* ロボット基準位置
* 干渉チェックする既知物体
* 干渉チェックするMap
* ロボットが持っているもの
* 距離計算の際の関節角の重み
* IKの際の関節角の重み
* 関節角度を関節角度に変換する任意の拘束．連動する関節の表現などに使う．常に働く．
* 関節角度を関節角度に変換する任意の拘束．初期値サンプリング時のみ
* 関節角度を関節角度に変換する任意の拘束．終端値サンプリング時のみ

を与えて計画を行う．このうち初期姿勢と初期姿勢TSRはあわせて１つは
与えなくてはいけない．終端姿勢についても同様である．

これらをRobotCbiRRTPlannerのPlanPathメソッドに与えることで
解軌道を得ることができる．

偏サンプリング
============================
初期姿勢を中心にした正規分布で，goalやstartをサンプリングすることで，比較的短い軌道を生成
できるようになる．標準偏差を小さくとれば最適性は上がるが探索範囲は狭くなり，大きくとれば
最適性は下がるが探索範囲は大きくなる．一様分布は最も探索範囲を大きくしたものである．

外部拘束
=============
プラグインによる拘束が自由に設定できる．TSRによる拘束は初期姿勢，終端姿勢では無効だが，
外部拘束は有効とする．

テスト仕様
============================

基本的には，ロボットに対してきちんとパスがでるかを確認する. パスの確認は
すべてのポイントで初期値，終端値が仕様を満たす，連続である，干渉していない，関節可動域内
という観点で調べる．

1. birrtと同様の使い方でパスがでるか確認
2. マルチ初期値，マルチ終端値でそれらをすべて使ったパスがでるか確認
3. constrain\_tsrをいれて拘束された軌道が出るかを確認
4. goal\_tsrs, start\_tsrsに対応した軌道が出るかを確認
5. 正規分布でのゴールサンプリングが有効になることを確認
6. タイムアウトが有効なことを確認
7. タイムアウトがほぼ指定された時間で終わることを確認
8. 初期値と終端値が同じ，もしくはほぼ同じで問題が出ないことを確認
9. 関節毎に重みをつけたときに，刻みが細かくなることを確認
10. IKの重みをつけたときにその関節が動き難くなることを確認．
11. IKと関係ない関節に目標値を適切に与えられるかを確認．
12. 任意の拘束（首と肩が連動する）を加えて正しく動くかを確認．
